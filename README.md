Some of the advantages of go routines are that they take up less memory than traditional threads, They are managed by go runtime, whereas threads are managed by the operating system. This could lead to more overhead associated with managing threads as opposed to go routines, and go routines use a method called channels to communicate with each other, as opposed to threads that use interprocess communication and shared memory addressing. Go’s syntax also makes it easier to understand what is going on. 
	Some of the disadvantages of go routines are that it is still relatively limited in the amount of libraries that it provides, and it’s limited capacity for cross compilation relative to other programming languages.
